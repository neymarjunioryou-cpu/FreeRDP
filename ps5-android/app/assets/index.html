About running PS5 games

PS5 titles are x86-64 binaries that are signed, encrypted and tied to the console's custom AMD APU and OS. There is no PS5 emulator for Android, and this project cannot execute PS5 game code. To play your own PS5 games on an Android device, stream them from your console with a Remote Play client.

Remote Play

OWN CONSOLE REQUIRED
01

Prepare your PS5

On the console: Settings → System → Remote Play, enable it, then Settings → System → Remote Play → Link Device to get the 8-digit code. Keep the console on the same network (or set up port forwarding).

02

Install an open-source client

Chiaki-ng is the actively maintained open-source PS4/PS5 Remote Play client for Android. It implements the remote play protocol itself; this shell deliberately does not bundle or copy that protocol code.

github.com/streetpea/chiaki-ng ↗ Latest APK releases ↗
03

Pair and play

Enter your PSN account ID / registration code in the client, wake the console, and pair a DualSense over Bluetooth. Use the Control Center here to tune the overlay while you get familiar with the layout.

Official PS Remote Play ↗
Why this isn't a PS5 port

Reverse engineering PS5 system software or commercial game binaries would require the encrypted firmware/game images, breaking DRM and circumventing platform protections, and would still need an x86-64 + custom GPU emulator that does not exist. Nothing from Sony's software is included here.

About

v1.0

PS5 Shell

An original Android app that recreates the feel of a modern console: boot splash, home screen, horizontal card row, Control Center, a full DualSense-style touch controller with two sticks, d-pad, four face buttons, L1/L2/R1/R2, touchpad, Share, Options, PS and Mute, plus hardware gamepad input forwarding.

It ships with Neon Drift, a small HTML5 game so every control can be tried immediately.

How it was built

REA (Reverse Engineer Anything, morluto/rea) was installed and used for the analysis pass. The FreeRDP Android client in this repo and Chiaki-ng's Android touch-control code were read as reference for input mapping and structure. Findings are in docs/REVERSE_ENGINEERING.md.

The APK is compiled offline: aapt2 + apktool/smali + apksigner, with no Gradle or Android Studio. See tools/build.py.
